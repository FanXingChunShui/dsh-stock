# 股票冲浪（dsh-astock）

给 DeepSeek-Harness 加一副「看盘评估」的面孔：一个 Web 面板，加上五个 Agent 工具。

> 侧栏与面板显示名为「股票冲浪」（英文环境 `Stock Surf`）；包名保持 `dsh-astock` 不变，
> 以免改 id 导致自选股等配置丢失。

- **Web 面板**：侧栏 `股票冲浪` 图标 → 主面板，三个 tab：
  - **个股**：搜代码、读评分、看因子拆解、管自选股
  - **板块**：一级行业 / 二级行业 / 概念板块排行与涨跌评估
  - **列表**：A 股 / 港股 / 美股热门标的，点进去看详情，行内一键加自选
- **Agent 工具**：`astock_evaluate` / `astock_quote` / `astock_search` / `astock_sectors`，在对话里直接问「帮我评估一下 600519」「看看今天的板块」。
- **数据来源**：腾讯免费公开行情接口（实时快照 + 前复权日 K），无需 API key、无需注册。
- **评分**：6 因子技术面打分，全部在本地计算。不外传任何数据，不写任何密钥。

> ⚠️ 免责声明：本工具是技术指标计算器 + 启发式评分器，**不是投资建议，不预测涨跌**。所有评分、评级与「上行倾向」都是启发式估计，非概率模型输出。数据可能延迟或缺失，技术指标可能失效，请自行独立判断并承担投资风险。

## 安装

```bash
# 方式一：让 Harness 自己装（推荐）
# 对 agent 说：安装 /path/to/dsh-astock 这个 bundle

# 方式二：手动挂到 profile 的 cordis.patch.yml
- insert:
    - id: astock
      name: 'dsh-astock'   # 或用绝对路径 file:///path/to/dsh-astock/index.js
      config:
        enabled: true
        defaultDays: 320
        timeoutMs: 8000
```

装完刷新 Web GUI，侧栏出现 `A股评估` 图标。

## 评分模型

综合分 0-100，六因子加权（权重和为 1，降级因子退回 50 分中性，**不重新分配权重**）：

| 因子 | 权重 | 看什么 |
|---|---|---|
| 趋势 trend | 0.28 | MA5/10/20/60 排列、价格相对均线位置、MA20 斜率、MACD 方向 |
| 动量 momentum | 0.22 | RSI14、MACD 金叉死叉与柱体、多周期收益率（1/5/20/60 日） |
| 量能 volume | 0.18 | 当日量价配合、5 日/20 日均量比、近 10 日放量方向 |
| 位置 position | 0.16 | 60 日/250 日区间分位、布林 %B |
| 波动 volatility | 0.10 | ATR 占现价比例、布林带宽 |
| 风险 risk | 0.06 | 连续涨跌天数、MA20 乖离、涨跌停接近度、异常量比 |

两个刻意的设计决定：

1. **区分趋势市与震荡市**。同一个 RSI 高值，在趋势市是「强势延续」，在震荡市是「区间超买」。引擎先判市场状态，再决定用趋势跟随还是均值回归的映射曲线；否则横盘会被系统性误判成单边。
2. **极端加速不给满分**。+2%/日 复利 260 天必然是抛物线，此时 RSI 极高、偏离 MA20 近 20%、连涨 259 天，扣风险分是真实的风险溢价。所以总分在极端区间**不再单调递增**——刻意保留，不为了曲线好看而削弱风险提示。

判定阈值：`≥75 强烈看多 / ≥60 偏多 / ≥45 中性 / ≥30 偏空 / <30 强烈看空`。

## Agent 工具

| 工具 | 用途 |
|---|---|
| `astock_evaluate` | 评估一只或多只（最多 10 只），返回完整评分对象并渲染中文摘要 |
| `astock_quote` | 实时快照：现价、涨跌、开高低、量比、换手、PE/PB、市值、涨跌停价 |
| `astock_search` | 名称 → 代码解析，如「茅台」→ `sh600519` |
| `astock_sectors` | 板块排行与评分：`boardType`（hy/hy2/gn）、`sortBy`、`order`、`limit` |
| `astock_detail` | 公司业务介绍与最新公告：`code`、`announcementLimit` |

## 数据源说明

单一数据源：腾讯 `qt.gtimg.cn`（实时快照，GBK 编码）与 `web.ifzq.gtimg.cn`（前复权日 K）。

为什么不用东方财富：它的接口默认解析到 IPv6 会直接 `Empty reply`，必须强制 IPv4 才通，且有 60-90 秒限流冷却。对面板轮询不友好，因此不用。

工程约束：

- 30 秒内存缓存，避免面板反复刷新打爆接口。
- 指数没有买卖五档，字段数少于个股，解析按数组长度防御，缺失字段返回 `null` 而非 `NaN`。
- 日 K 数组长度不恒为 6，除权日会多出第 7 位（分红对象），解析只取前 6 位。

## 依赖说明（重要）

插件只依赖一个运行时包：`@deepseek-ai/schemastery`（Cordis 的配置 schema 库，profile 里已经有）。

它必须写在 `dependencies` 而**不是** `peerDependencies`：pnpm 在 `nodeLinker: hoisted` + `autoInstallPeers: false` 下不会为 peer 依赖建立可解析的链接，会导致 `ERR_MODULE_NOT_FOUND`。

本目录的 `node_modules/@deepseek-ai/` 里是指向 profile 的符号链接，只为让本地 `node --test` 能跑通；正式安装时 `plugin_manager install_bundle` 会自己处理。

## 排错

**面板所有请求报 `HTTP 405` / `transport failure` / `watchlistFailed`**

这是 RPC 通道没挂载上，不是网络或鉴权问题。判定方法：未带凭据访问通道时，**已挂载返回 401，未挂载返回 404/405**：

```bash
curl -o /dev/null -w '%{http_code}\n' -X POST http://127.0.0.1:<端口>/astock/indices -d '{}'
```

根因通常是 Host 端用了 `connection.rpc.handle()` 而不是 `connection.register(ctx, channel, handler)`——前者会抛 `cannot get property "webServer" without inject`，被 Loader 静默记为 entry 未激活。正确写法见 `CONTRACT.md` 的「Host 端注册方式」。

## 已知限制

- 覆盖 A 股（沪/深/北）、港股、美股与主要指数；不含期货、期权、外汇。
- **港股列表只有 60 只**：免费源 `getHKStockData` 的 `qbgg_hk` 节点实测只返回 60 条（`num` 提到 1000 仍是 60），这是源上限，界面已如实标注「非全量」。
- **美股没有免费全量列表**：列表页只列 32 只常用标的，其它美股请用搜索框按代码/名称查找。
- 港美股无涨跌停价字段，相关风险提示不适用。
- **K 线图为自绘 SVG**：不依赖任何图表库（保持零运行时依赖），支持蜡烛、均线、成交量、hover 提示；暂不支持缩放、拖拽、十字光标。
- **一键解读是规则化文案**：由技术指标按固定规则拼接，不是 LLM 生成，也不做涨跌预测。措辞刻意避免「必涨/必跌」这类断言。
- **公司资料（F10）只有 A 股**：东财 F10 接口不覆盖港股美股，详情页会显示「暂无公司资料」。
- **板块成分股走东财 datacenter**：腾讯板块码（`pt01801120`）与东财板块码（`896`）不通用，需先按板块名反查。东财 `push2*` 行情域名在本机不可达，但 `datacenter-web` / `emweb` / `np-anotice-stock` 可用。
- 板块评分基于截面数据，与个股评分口径不同，两者不可直接横向比较。
- 纯技术面，不读财报、公告、资金流、龙虎榜、北向资金。
- 实时快照在收盘后为当日收盘数据，非盘中实时。
- 首次打开面板会并行拉取指数与自选股，弱网下首屏可能等待 1-2 秒。
